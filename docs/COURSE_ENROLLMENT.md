# 选课与我的课程

Learning 服务沿用 API → Service → Model 三层：现有 LearningCourseController / LearningCourseService / LearningCourseServiceImpl 扩展选课入口，CourseEnrollmentDto 放在 learning_model。复用已有 JWT 认证、Spring Security、CSRF、JDBC 与 MySQL，不新增依赖或微服务。

## 部署

当前选课表位于 learning 库。新部署使用 [六库初始化](sql/INIT_DATABASES.sql)；历史增量迁移脚本已移除。已有 class 学习表的环境需按实际数据制定迁移方案，不能建空表代替历史记录。Content 的数据源为 class，Learning 为 learning，配置分组仍为 sunflower_class；历史归属调整见 [数据库归属说明](DATABASE_OWNERSHIP.md)。

停止本项目服务后执行 `mvn -f base/pom.xml install`、`mvn -f learning/pom.xml install`，再重启各服务，避免运行中覆盖共享 JAR。学员端执行 npm run build，开发端口仍为 5174。Gateway 的 /learning/** 路由继续复用，无需新增路由。

## 行为和状态

- 免费课程：发布快照 charge=30201 时保存选课类型 70101、成功状态 70201、价格 0；查询资格 70301。快照 validDays>0 时，从选课时刻起计算有效期；null 或 0 表示不限天数。
- 收费课程：charge=30202 时保存类型 70102、待支付状态 70202 和服务端价格/有效天数快照；学习资格为 70302，没有支付前有效期。创建支付订单、付款与支付后开通是后续独立功能，本次没有支付成功入口。
- 同一学生和同一课程有唯一主键。事务锁定发布副本后检查已有记录，重复或并发请求返回相同记录，不改变原价格、创建时间或有效期；重新选课不会给过期资格续期。
- 学生 ID 只从已验签 JWT subject 读取。价格、收费方式、选课状态与资格不接受正文覆盖；机构和审核员无学生接口权限，直接访问 Learning 端口同样校验。
- 我的课程按服务端当前学生条件分页，包含待支付、已过期、已下架记录。过期返回 70303；未支付、未选课或发布副本已下架返回 70302。课程下架后保留已选记录和价格快照，重新发布后只有仍在有效期内的成功记录恢复资格。
- 发布状态依赖已有 RabbitMQ 消费副本，沿用最终一致性。公开课程目录仍可匿名查询，目录可见不等于学习资格；受保护视频地址及播放鉴权已接入，见 [播放说明](COURSE_PLAYBACK.md)。

## 接口

以下路径经过 Gateway，学员端使用 /api 前缀。接口只接受 student，POST 必须携带与 Cookie 配对的原生 CSRF 请求头。

| 方法与路径                                     | 行为                                                                             |
| ---------------------------------------------- | -------------------------------------------------------------------------------- |
| POST /learning/enrollments/{courseId}          | 选课或返回已有选课；不存在、未发布或下架返回 404                                 |
| GET /learning/enrollments/{courseId}           | 当前学生选课及实时资格；已发布但未选课返回资格 70302，空字段按已有 JSON 配置省略 |
| GET /learning/enrollments?pageNo=1&pageSize=10 | 我的课程分页，pageNo 至少 1，pageSize 为 1～100；越界参数返回 400                |

字段包括 courseId、name、enrollmentType、status、price、createdAt、expiresAt、qualification、courseAvailable；不返回用户 ID、密码、JWT 或视频地址。无身份返回 401，无学生角色或 CSRF 失败返回 403；收费方式、价格或有效期快照异常返回 409。

学员课程详情中未登录选课会跳转登录并返回原课程；成功和待支付状态可刷新恢复。“我的学习”展示数据库记录、有效期与下架/过期提示，资格有效时提供现有学习目录入口。有效资格可进入真实视频播放；收费课程已接入订单及支付宝沙箱入口，真实付款和公网回调验收状态见 [支付验证记录](ACCEPTANCE_ORDERS_PAYMENT.md)。

## 重构已确认的有效期与续期规则

以下为用户确认的重构规则，需对照代码验证，不能据此宣称新增逻辑已实现。

- 免费课程从选课成功时起计算有效期，收费课程从实际付款成功时间起计算；无期限课程明确表示长期有效。
- 重复选课、支付通知及事件重放不重置或延长已有资格。取得资格时的规则保持不变，课程后续修改价格、有效期不追溯改写。
- 免费资格到期后仅本人可以续期，课程必须仍正式发布且免费，按最新发布版本的有效期重新计算；未到期不能通过续期延长时间，改为收费后不再免费续期。
- 收费资格到期后的重新购买不纳入本轮新增实现，另行确定订单与资格更新规则。
- 下架期间暂停播放和免费续期，但资格有效期继续计时，不自动顺延；页面提前说明，补偿规则不纳入本轮。
