# 学成在线项目需求文档

## 1. 目标与范围

建设一个基于当前 `content`、`media`、`gateway` 模块的在线课程后端，让机构能够创建并发布课程，让学员能够搜索、选课和学习，收费课程通过订单支付获得学习资格。交付顺序见 [开发清单](DEVELOPMENT_CHECKLIST.md)。本项目不开发课程预览功能，也不要求生成课程静态页面；已发布课程通过接口提供展示数据。前端页面可在独立项目实现，不作为本仓库后端验收的前提。

## 2. 角色与业务对象

| 角色 | 能力 |
| --- | --- |
| 机构人员 | 管理本机构课程、教学计划和媒资，提交审核，发布已通过审核的课程。 |
| 审核员 | 查看待审核课程，记录通过或驳回结果与原因。 |
| 学员 | 浏览和搜索已发布课程，选课、支付、查看我的课程并学习。 |

核心对象包括课程基础信息、营销信息、教学计划、媒资文件、预发布记录、正式发布记录、发布消息、用户、选课记录、订单和支付记录。课程 ID 与机构 ID 必须在跨服务调用中保持一致。

## 3. 功能需求

### 3.1 课程管理与审核

- 机构可创建、查询、编辑和删除本机构未发布课程，维护分类、收费方式、价格、教学计划及媒资关联。已发布课程须先下架，不能直接删除；删除时应处理关联数据且不删除仍被其他课程引用的媒资文件。服务端校验必填字段、价格和归属机构；其他机构不得修改。
- 机构可删除教学计划节点并调整同级节点顺序；删除含子节点或媒资绑定的节点时须显式处理关联关系，调整顺序后查询结果应稳定一致。绑定媒资前验证文件存在、处理完成且属于当前机构。
- 提交审核前，课程必须有营销信息和教学计划；需要视频的小节必须关联可用媒资。提交后进入“审核中”，不得直接发布。
- 审核员可通过或驳回，并保存操作人、时间和驳回原因。驳回后机构可修改并重新提交。审核状态与发布状态分别维护，不得混用字段。

### 3.2 课程发布与发现

- 只有审核通过的课程可发布。发布时保存课程快照和待发送消息；两者必须同事务成功或失败。
- 消息发送失败要可重试，消费者按课程 ID 与版本幂等处理；重复发布不得产生重复课程或消息副作用。
- 已发布课程提供公开列表、详情和关键词/分类搜索；未发布或下架课程不出现在学员查询结果中。发布、更新、下架后，搜索数据应最终与正式发布记录一致。

### 3.3 媒资与视频处理

- 机构可清理本机构不再使用的媒资；被教学计划或已发布课程引用时拒绝删除并提示先解除关联或下架。删除须处理转码任务、媒资记录与对象存储文件，失败时可恢复，不影响其他课程仍在使用的文件。

- 支持普通上传、分片续传、合并、文件存在性检查和课程小节绑定。已上传分片可跳过重传；合并前确认分片齐全，上传及合并后校验文件完整性。失败时清理临时分片、不完整对象和对应的不完整记录，不误删已存在的有效文件。
- 视频上传后进入转码队列；记录待处理、处理中、成功、失败状态和错误原因。失败任务按统一上限重试；达到上限后保留记录供人工处理。
- 获取播放地址前校验课程发布状态和学员学习资格；不向未授权用户返回受保护视频地址。

### 3.4 认证、选课与支付

- 用户登录后取得可验证的身份令牌。网关验证令牌，业务服务从可信身份中读取用户/机构 ID；审核和管理接口按角色授权。
- 免费课程选课成功后立即开通学习资格。收费课程创建待支付订单，确认支付成功后开通资格；同一学员对同一课程的重复请求不产生重复有效选课。
- 订单保存课程及价格快照，并可生成与订单关联的支付二维码。支付通知须验签、校验订单与金额并幂等处理；超时未支付订单不得开通资格。学员可查询订单状态和“我的课程”课程表。

## 4. 非功能与验收要求

- **可靠性**：数据库变更和跨服务消息采用可恢复方案；日志包含业务 ID、消息 ID 和错误原因，不记录密码或支付密钥。
- **安全性**：关键操作校验身份、角色和数据归属；配置与凭据放在外部配置中心或环境变量。
- **测试**：至少覆盖审核状态流转、跨机构访问、课程及教学计划删除、重复发布、消息重试、断点续传、文件损坏、异常清理、转码失败、重复支付回调和无资格播放；完成上传→转码→绑定的端到端测试。
- **运行**：提供 Java 21/Maven 构建说明、Nacos 配置样例及 MySQL、RabbitMQ、MinIO、FFmpeg 依赖说明。验收时 Gateway、Content、Media 同时运行，网关经 Nacos 发现并路由到两个业务服务，再按“建课→审核→发布→搜索→选课/支付→学习”完成接口联调。
