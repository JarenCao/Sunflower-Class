# 登录与 JWT 身份验收

日期：2026-10-01。状态：开发、真实前后端联调和技术验证完成，用户于同日明确回复“确认验收”，本功能验收通过。本次只完成 P1 第一项登录与身份认证；未继续开发完整角色权限、选课或播放资格。

## 本次功能

- 机构端和学员端新增真实登录、身份显示和退出入口；刷新通过后端恢复身份，匿名访问管理页转到登录页并保留目标路径。
- Content 使用数据库账号和 BCrypt 密码散列签发三十分钟 JWT；令牌放入 HttpOnly、SameSite=Lax Cookie，密码和 JWT 不进入浏览器存储，登录 JSON 不返回 JWT。
- Gateway 及业务服务使用框架验签，核对签发者与有效期；直接访问 Content、Media 端口不能绕过身份验证。所有写请求使用原生 CSRF 校验，Cookie JWT 不享受 Bearer 请求的自动豁免。
- 课程、教学计划、媒资和消息接口从已验证身份获取机构编号；新增课程不接受客户端机构编号覆盖身份。审核记录读取登录用户显示名，Content 调用 Media 时传递 JWT 并再次验签。
- 连续五次登录失败锁定账号十五分钟。请求日志对登录凭据脱敏，中文密码按 UTF-8 字节限制 BCrypt 的 72 字节上限。
- 搜索、详情、正式目录保留匿名访问；正式发布快照引用的图片封面可公开查看，视频不开放匿名访问。

## 真实验证

临时脚本只放在 Git 忽略的 `.runtime/`，没有新增需提交的测试源码。经机构端 5173、学员端 5174 的真实 Vite 代理和 Gateway 完成 **57 项断言**，包括：

| 范围       | 结果                                                                                                                 |
| ---------- | -------------------------------------------------------------------------------------------------------------------- |
| 登录与退出 | 两种账号可登录；Cookie 属性、刷新身份、退出清 Cookie、退出后 401 正常                                                |
| JWT 边界   | 无效、过期、错误签发者令牌及只有伪造身份头的请求均被拒绝                                                             |
| CSRF 边界  | 无令牌的登录和已登录写请求被拒绝；伪造 CSRF 返回 403                                                                 |
| 机构身份   | 本机构列表隔离；另一机构不能读取课程编辑详情；学员不能伪造机构身份；创建时忽略请求中的机构编号                       |
| 密码与锁定 | 错误密码拒绝；五次失败后正确密码也被锁定；空账号、超过 72 字节的英文和中文密码返回 400                               |
| 旧 Cookie  | 失效 Cookie 不能认证，但仍可获取 CSRF 并重新登录                                                                     |
| 原发布流程 | 临时课程 156：创建、目录、真实视频绑定、提审、审核、发布、搜索和学习目录查询、下架、删除全部通过；审核人来自登录身份 |
| 文件访问   | 真正跟随对象存储签名链接读取公开封面成功；匿名视频请求被拒绝                                                         |

内置浏览器实际操作：机构登录、课程管理加载、刷新仍保持登录、退出；学员登录显示“验收学员”、退出后公开浏览；匿名进入机构课程页转回登录。截图位于 `.runtime/auth-admin-acceptance.png` 和 `.runtime/auth-student-acceptance.png`。

## 用户验收

1. 打开机构端 `http://localhost:5173/login`，使用 `sunflower-institution` 登录；检查显示名、课程管理和媒资中心，刷新后应保持登录。

3. 打开学员端 `http://localhost:5174/login`，使用 `sunflower-student` 登录，检查显示“验收学员”；退出后仍可浏览公开课程。
