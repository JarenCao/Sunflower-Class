# 学成在线开发清单

本清单以当前仓库为基线，按依赖关系安排开发。`[x]` 表示仓库中已有基础实现，尚不代表端到端验收通过；`[ ]` 表示待完成。业务规则和验收标准见 [需求文档](REQUIREMENTS.md)。课程预览不在本项目范围内。

- [x] 课程编辑页“关联媒资”支持直接上传、进度与取消，上传后刷新并选择媒资。已完成真实页面和接口联调，待用户验收，见 [验收单](ACCEPTANCE_EDITOR_MEDIA_UPLOAD.md)。
- [x] 增加未发布课程删除；已发布课程先下架，删除时处理教学计划、营销信息与媒资关联。用户已验收通过，见 [验收单](ACCEPTANCE_COURSE_DELETE.md)。

- [x] 课程切换时清空上一门课程的教学计划状态；旧课程缺少营销记录时仍能显示真实目录，并阻止重复添加。用户已验收通过，见 [验收单](ACCEPTANCE_TEACHPLAN_ISOLATION.md)。

## P1：身份、课程发现和选课学习

- [ ] 建立用户登录及 JWT 身份认证，网关校验令牌；机构和学员身份从令牌获取，移除写死或由请求直接指定的 `companyId`。
- [ ] 增加角色/权限控制：机构维护本机构课程，审核员处理审核，学员选课与学习。
- [ ] 建立 Elasticsearch 课程搜索索引，消费发布/变更/下架事件；支持关键词、分类、分页查询。
- [ ] 实现免费课程选课、收费课程待支付选课；查询学习资格与“我的课程”课程表。
- [ ] 实现课程目录、视频地址获取和播放资格校验；仅已获得资格的学员可访问受保护媒资。
- [ ] 验证普通上传与分片断点续传；核对分片和合并文件完整性，失败时清理临时对象及不完整记录。
- [ ] 统一转码状态、重试次数和定时重试条件；提供失败任务处理途径并补上传→转码→绑定的端到端测试。
- [ ] 媒资中心增加安全删除：仅本机构可删除未被教学计划或发布课程引用的文件；处理中任务先停止/清理，数据库记录、MinIO 对象及转码产物保持一致，失败可重试；前端提供引用提示和二次确认。

## P2：交易、稳定性和交付

- [ ] 实现订单创建、价格快照、支付二维码、异步支付通知、状态查询及超时订单处理。
- [ ] 支付成功后可靠通知学习服务开通资格，防止重复通知造成重复开通。
- [ ] 为高频课程详情/列表增加 Redis 缓存，处理失效和数据一致性；用性能测试决定是否继续优化。
- [ ] 补齐数据库初始化脚本、Nacos 配置样例、容器启动说明和三项服务的联调步骤。
- [ ] 在 CI 中执行编译与关键测试，并记录运行所需的 MySQL、Nacos、RabbitMQ、MinIO 和 FFmpeg 配置。

## 阶段验收

1. **发布闭环**：机构建课、上传并绑定视频、提交审核、审核通过、发布后，可通过公开接口查询课程；失败消息可恢复。
2. **学习闭环**：学员登录、发现课程、完成免费选课或取得付费资格，能观看有权限的视频，未授权请求被拒绝。
3. **交易闭环**：订单支付与学习资格状态一致，重复回调和故障重试不会重复开通。
