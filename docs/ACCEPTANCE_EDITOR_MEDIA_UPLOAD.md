## 本次功能

- 编辑课程的“关联媒资”步骤新增“选择文件上传”入口，复用媒资中心已有的普通上传、视频分片上传和断点续传接口，不增加后端接口。
- 上传时显示进度与处理阶段，可以停止请求；重新选择同一文件时仍由服务端检查已有分片。图片等普通文件上传后刷新媒资列表并自动选中，选择小节即可绑定。
- 视频上传后按现有转码流程处理，可点击“刷新列表”查看最新状态；未处理完成的文件在选择列表中禁用，转码完成才能绑定。已存在的完整视频会提示从媒资列表选择。审核中或已发布的课程禁用上传及绑定入口。
