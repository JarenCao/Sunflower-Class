# 机构老师账号验收单

日期：2026-10-02。状态：技术验证通过，等待 P1 统一验收。

复用 Auth 三层及 users 数据库。启用的 teachmanager 机构管理员可分页查看本机构账号并创建老师。服务端使用当前身份与实时数据库机构归属，事务保存 user、company_user 和 teacher 角色。禁止请求指定其他机构、审核员或平台管理员角色；普通老师、学员、审核员不能管理账号。平台角色没有借此开放申请入口。

## 校验结果

- 既有实时老师创建验证 14 项通过，包括创建事务、角色关联、老师登录、分页不泄露密码、重复账号、权限和机构隔离。
- 本轮账号补验 19 项通过，额外核查 JSON 格式、真实管理员权限和伪造机构/管理角色拒绝。
- 浏览器：管理员显示老师账号入口及真实列表；新老师可登录，页面没有账号管理入口，直接打开 /teachers 会返回工作台。

## 人工验收

用原 sunflower-institution 管理员登录 http://localhost:5173/teachers，填写老师账号、姓名和初始密码；账号创建后应出现本机构列表。退出并使用该老师登录，能进入课程和媒资管理，不能管理账号或审核课程。
