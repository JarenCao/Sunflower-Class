# 选课与我的课程验收

日期：2026-10-01。状态：实现、真实前后端联调及技术检查完成，用户于 2026-10-01 确认验收通过。本次只完成开发清单中的选课项；不开始视频播放和支付订单功能。

## 已实现

- Learning 仍为 learning_model、learning_service、learning_api 三层。扩展已有控制器/业务接口/实现，必要响应 DTO 放在 Model，接口层不直接操作数据库。复用已有 JDBC、JWT、CSRF、MySQL 事务及 Vue 页面，无新依赖或额外微服务。
- 当前 class 库新增 course_enrollment，按 user_id/course_id 唯一。免费选课立即成功并开通资格；收费选课保留价格/有效天数快照与待支付状态，不能获得资格。
- 身份来自 JWT subject，价格和收费方式来自正式发布副本，正文中的 userId、price、charge、status 或 qualification 不能覆盖结果。机构、审核员和匿名用户不能访问学生记录；直连 Learning 仍检查角色。
- 复用实际 system.dictionary 的 701/702/703 五位编码：免费/收费类型、成功/待支付状态、可学习/无资格/已过期资格各自分开，见 [状态规范](STATUS_CODES.md)。
- 重复或并发选课返回原记录，不修改创建时间、价格或有效期。免费 validDays>0 时从首次选课计时，过期查询失效，重复请求不能续期。
- 我的学习只读当前学生记录并服务端分页，保留待支付、过期和下架课程。下架资格失效，重新发布后仍有效的成功选课恢复资格；继续沿用消息同步的最终一致性。
- 课程详情选择后即时显示状态，可进入我的学习；页面刷新重新读取数据库，无浏览器存储或演示回退。免费资格提供已有公开学习目录入口，视频播放仍显示待开放。

- 11 项前置与权限检查通过：原机构/审核员/学员登录，两门课程经 Content、Media、独立审核、发布和 RabbitMQ 同步；机构/审核员拒绝选课及读取学生记录，匿名拒绝，缺少 CSRF 拒绝。

## 用户验收

1. 学员端用原 sunflower-student 登录，进入 http://localhost:5174/my-courses，确认两门验收课程与成功/待支付状态，刷新验证仍保留。
2. 查看课程 159：显示已选课、已开通资格；我的学习显示到期时间，并提供学习目录入口。视频播放属于下一项，不在本次验收。
3. 查看课程 160：显示待支付、未开通资格及 ¥19.9，重复进入或选课不会重复记录；目前不提供实际付款。
4. 使用其他有效学生账号可独立选课，它的我的学习不包含验收学员记录。机构或审核员无法调用学生接口。
