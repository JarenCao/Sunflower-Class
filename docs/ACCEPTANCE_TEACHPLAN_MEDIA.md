# 教学计划编排与媒资绑定验收单

日期：2026-09-27。状态：用户已确认验收通过。

## 已实现

- 机构端可删除章或小节；删除章会连带清理小节、媒资绑定和作业关联，媒资文件保留。删除前显示影响范围并要求确认。
- 章和小节分别在同一父节点内上移、下移一位；移动或删除后重新生成连续排序号，页面以服务端顺序刷新。
- 查询、保存、删除、排序和媒资绑定校验课程机构归属；已发布课程不可修改教学计划或绑定。
- 绑定前通过 Nacos 发现媒资服务，核对文件归属、处理完成状态及 MinIO 对象存在性；文件名以媒资库为准。校验失败时保留原绑定。
- 新增接口、函数及关键业务分支均有中文注释。

## 验证结果

| 场景 | 结果 |
| --- | --- |
| 机构端新增章、上移章、绑定视频 | 页面和数据库顺序一致，真实文件名显示在小节下 |
| 章和小节分别同级上移 | 同级顺序正确，序号连续；其他层级不受影响 |
| 取消删除 | 目录保留 |
| 删除含两个小节的章 | 章、小节、绑定及历史空 `course_id` 作业关联均清零；其他章重新编号 |
| 单独删除小节 | 该小节及绑定清零，所属章保留 |
| 非本机构保存、删除、排序、绑定 | 请求均被拦截，原记录保持不变 |
| 已发布课程排序 | 请求被拦截，原顺序保持不变 |
| 不存在或待转码媒资 | 绑定被拒绝，旧绑定保留 |
| 他机构媒资、仅有数据库记录但对象不存在 | 媒资服务返回 404，不作为可绑定资源 |
| 共享视频 | 删除计划后文件仍返回 200 |

内容和媒资 Maven 构建、机构端 TypeScript 检查及生产构建均通过。机构端构建仍有既有的大包体积提示。运行环境为 Windows 本机 Java/Maven/Vite，连接 WSL2 Ubuntu Docker 中现有 MySQL、Nacos、RabbitMQ、silo-server；未在 Ubuntu 安装软件。

临时课程 138、计划 297–302、作业关联及三条临时媒资元数据已清理，数据库残留为 0；现有课程及媒资文件未删除。
