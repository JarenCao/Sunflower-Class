# 媒资安全删除验收单

日期：2026-10-02。状态：技术验证通过，等待 P1 统一验收。

引用查询在 Content 的 Controller→现有 CourseBaseInfoService→课程数据库完成；Media 使用自己的 Service、Mapper 和 media 数据库清理。只允许本机构删除未引用媒资；教学计划、封面、审核中/通过快照及已发布快照均阻止删除。引用服务不可用时拒绝删除，避免误判为零引用。

持有 MySQL 命名锁协调绑定、封面保存和删除；先持久化 20305 删除中，取消实际 FFmpeg 容器，再清理源对象、转码对象、任务、历史和文件记录。清理失败返回 503，保留原路径与错误，可重新删除；取消尚未结束返回 202，稍后重试清理，全部完成返回 204。共享对象保留到最后一个媒资解除。本项目服务数据库位于同一 MySQL 实例，命名锁依赖该部署条件。

## 校验结果

- 删除边界及故障恢复 21 项：教学视频与封面 409；匿名、学员和跨机构拒绝；真实对象存在→删除→全部元数据和对象消失；重复删除 404；模拟专用测试桶不可用后保留删除中和错误，恢复后重试成功；共享对象、缺失存储位置及原记录完整性。
- 取消与并发 13 项：实际 FFmpeg 进入处理中后删除，任务、历史、原对象和转码对象清除；绑定与删除并发不能产生孤立关联；专用教学节点清理；审核员不能删除；原媒资不变。
- 成功转码及清理 8 项：新视频真实转码、历史原路径、原始/转码对象、归档清理以及 Windows/WSL 临时文件核查。
- 浏览器：已绑定文件显示真实引用次数且阻止删除；未引用文件弹出二次确认，取消后文件仍在。
- 最终数据库：专用 p1-delete-* 文件残留 0，孤立活动转码任务 0，class 仍只有 12 张课程/消息表；未误写其他数据库。
