## 人工验收

1. 学生登录后进入“机构入驻”，提交一个新的专用申请。
2. 平台管理员登录管理端，查看申请、填写理由并审批。
3. 使用申请时填写的新管理员账号登录管理端，确认只能管理新机构。
4. 原学生账号仍可登录学习端；驳回申请的管理员账号不能登录。

补充边界校验：邮箱含 utf8mb3 无法保存的字符时返回 400，真实接口确认申请数量不变；复用原字符校验方法并添加中文注释。机构验证合计 46 项，Auth 最后一次构建和重启通过。
