# 中文错误提示验收

## 本次修改

学员端与管理端共用 `frontend-shared/error-message.ts`。登录、注册、机构申请与审核、老师账号、课程维护与审核、媒资、搜索、学习、订单和退出的现有错误展示入口统一使用中文提示。

优先显示后端返回的具体中文业务原因，例如“管理员账号已存在，请选择新的账号”。没有具体原因时，根据 HTTP 状态分别提示输入错误、登录失效、权限不足、内容不存在、数据冲突、文件过大、请求频繁及服务异常；断网与超时单独提示。英文 Axios 错误、未知英文异常和异常堆栈使用中文提示代替。原有取消确认、停止上传、身份判断及 HTTP 状态保持不变。

媒资重试确认中的未知技术错误采用中文说明。退出失败时留在原页面并提示原因，允许重试。

## 开发校验（2026-10-05）

- `node --test frontend-shared/error-message.test.ts`：3 组通过，覆盖具体中文原因、HTTP 分类、英文兜底、堆栈、网络故障、超时和取消。
- `python scripts/check-utf8.py` 通过。
- 经真实 Vite 代理及网关校验 8 项：匿名身份 401、错误登录 401、无效注册 400、正常登录 200、无平台权限 403、无老师管理权限 403、课程不存在 404、管理员账号冲突 409。
- 真实浏览器确认管理端登录错误、学员端重复账号及课程不存在的中文提示；重复账号提交没有创建新申请。

超时、断网、429 和服务故障分类在自动化测试中校验，没有为了验证提示停用基础设施或进行真实付款。

3. 检查课程、学习、订单及管理端日常操作的失败提示是否易懂。
4. 正常操作和取消确认应继续正常工作。
