# 三角色权限与流程

2026-10-07：当前业务数据已清空，以下账号映射与验收结果记录此前实施过程；新环境开户和当前流程以 [项目梳理](PROJECT_GUIDE.md) 为准。

2026-10-05 已实施并完成开发校验，等待用户验收。

## 账号映射

| 现有身份   | 调整后身份 | 权限变化                                         |
| ---------- | ---------- | ------------------------------------------------ |
| 学员       | 学员       | 保留学习、订单及本人申请权限                     |
| 老师       | 老师       | 保留原机构的课程和媒资权限                       |
| 机构管理员 | 老师       | 保留教学权限，移除老师账号管理权限               |
| 课程审核员 | 平台管理员 | 保留课程审核；新增老师申请审核及老师账号管理权限 |
| 平台管理员 | 平台管理员 | 保留申请审核；新增课程审核及老师账号管理权限     |

现有课程审核员统一使用平台管理员身份。没有显式启用管理角色的账号不会仅因用户类型字段获得管理权限。

## 页面与流程

- 学员端和管理端两个入口保持不变。
- 管理员侧边栏统一显示课程审核、老师申请审核、老师账号。
- 老师侧边栏显示教学工作台、课程管理、媒资中心。
- 机构入驻改为申请成为老师，保留姓名、手机号、教学简介、老师账号、密码和确认密码六项。
- 复用已有申请表、行锁、账号唯一约束、密码散列及审核事务。旧申请和历史结论保留，旧接口路径可以继续兼容。
- 审核通过后开通独立老师账号，学员账号及学习记录保留。
- 新老师自动创建独立教学空间；旧老师保持原机构归属，不重新分配旧课程或媒资。
- 老师不能审核申请或课程，不能管理其他教学空间，不能创建老师账号。
- 角色调整后重新登录获取新身份，不能仅依赖前端菜单控制权限。
