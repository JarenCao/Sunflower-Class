# 课程删除与下架验收单

日期：2026-09-27。状态：用户已确认验收通过。

## 功能范围

- 机构端课程列表提供删除、下架及二次确认；取消操作不修改数据。
- 未发布、已下架课程可删除；已发布课程必须先下架。异常发布状态拒绝删除。
- 删除在事务内清理课程、营销、教学计划、媒资绑定、作业关联、教师、审核及发布记录；保留媒资文件。
- 下架同步更新课程与发布记录；学员端不再展示该课程，详情提示已下架或删除。
- 删除末页最后一条后自动回到上一页，每页仍为 10 条。
- 新增函数、接口与关键业务逻辑均有中文注释。
