# 受保护视频播放验收单

日期：2026-10-01。状态：技术验证通过，等待用户验收。本次仅实现受保护视频播放，下一项上传复验未开始。

## 本次结果

沿用 Learning、Media 的三层结构，为有效学习资格提供正式发布小节的短期转码视频地址；学员页面使用真实 video 播放。机构、审核员、未选课、待支付、已过期和已下架请求不能取得新地址。原有学生直接文件查看入口仍拒绝视频。

## 真实验证

- base、learning、media Maven 安装通过；学员端 vue-tsc 与 Vite 生产构建通过。
- 通过真实 Gateway、Auth、Learning、Media、MySQL、Nacos 和对象存储执行 28 项播放断言及 6 项隔离异常断言，共 34 项，全部通过。脚本与结果位于忽略目录 .runtime/playback-check.py、playback-results.json、playback-failure-check.py、playback-failure-results.json，不新增提交用测试。
- 覆盖身份/角色、免费有效资格、待支付、未选课、过期、下架与恢复、跨课程小节、章节编号、无效课程/小节、伪造身份/媒资参数、直接服务端口，以及普通视频入口绕过。
- 实际 MP4 对象返回 Range 206、Content-Range 和 MP4 文件头；签名有效期不超过 60 秒，到期后实际对象请求返回 403；授权响应 no-store。
- 隔离异常覆盖未完成转码、其他机构、图片冒充视频、对象缺失、媒资记录缺失；测试只使用临时媒资元数据，结束后恢复原发布副本并移除临时记录，原视频对象未修改。
- 浏览器登录原验收学员，免费课程 159 加载原生 video：readyState=4、duration=1 秒；点击原生播放后 currentTime=0.208522、paused=false、无错误。收费课程 160 显示未取得资格/未支付提示，没有播放器。

## 人工验收

使用原验收学员 sunflower-student，密码沿用本机 .runtime/login-accounts.json，不写入文档。

1. 打开 http://localhost:5174/my-courses，进入免费课程 159，点击播放，应出现真实验收视频（约 1 秒）。刷新、重新选择小节仍可播放。
2. 打开 http://localhost:5174/learn/160，待支付课程应显示资格提示，不能播放。
3. 课程下架或资格过期后重新申请地址应拒绝；地址有最长 60 秒的已签发有效窗口，已缓冲内容不能即时撤回。下架状态依赖学习副本消费完成。

两门原验收课程和两条学生选课记录保留，收费课程没有被开通。部署及接口见 [播放说明](COURSE_PLAYBACK.md)。用户确认验收后再等待“继续”进入下一项。
