# 教学计划按课程隔离验收

## 问题与处理

旧测试课程缺少 `course_market` 营销记录，详情接口返回“课程营销信息不存在”。编辑页原先先查询详情，再查询教学计划，导致已有章节被误显示为“暂无”；添加新章节后的刷新却读出了全部旧章节，看起来像一次添加了多章。

详情接口现在为缺少营销记录的旧课程返回免费课程默认值，保存课程时再写入营销记录。编辑页先独立读取教学计划，详情未加载成功时禁止编辑；切换课程时清空旧状态并丢弃过期响应，添加过程中禁止重复提交。已有章节未删除。

## 实际验收记录

- 机构端 `npm run build` 和后端 `mvn -f content/pom.xml install -DskipTests` 均通过。
- 修复前的 Gateway 实时接口确认课程 `100` 原有“第一节、4656、456、789、123”等章节，新增“465456”后仍在同一课程下；同时 `GET /course/100` 报“课程营销信息不存在”，复现了误显示为空的原因。
- 前一轮创建临时课程 `149`，初始接口返回 0 章；页面添加一次后只显示 1 章，接口也只返回 1 章；临时课程已删除。
- 2026-09-29 复验：Gateway 的 `GET /content/course/100` 返回课程详情和默认免费编码 `30201`；该课程当前教学计划为 0 条，机构端同步显示空状态。
- 对照课程 `84` 的接口返回 2 章，机构端在点击“添加”前即显示这 2 章及小节。
- 另建临时课程 `150`，初始为 0 章；通过机构端点击一次“添加”后，页面和接口均只显示“本次验收章节”这一章。临时课程已删除，按名称查询剩余 0 条。

## 用户验收

打开课程 `100`，进入“02 教学计划”，确认当前显示空状态；打开课程 `84`，确认在添加前就显示已有两章。新增一次只增加一章的流程已用临时课程完成，不需更改你的正式课程。技术联调与用户验收均已通过（2026-09-29）。
